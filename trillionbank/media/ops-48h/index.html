出演・掲載後の48時間

公開を知ってから48時間以内に完了する運用チェックです。

{% include tb-page-summary.html %}
0. 入力
  • 媒体名・番組名 / URL / 公開日
  • 分類: 代表出演 / 会社掲載 / 代表者 過去掲載 / 掲載予定 / 確認中
  • サムネ・ロゴ・引用の許諾
1. エンティティ照合（必須）
  • 法人名と通称が Press Kit と一致している
  • 旧社名 Regalis を現在の商号にしていない
  • 銀行誤認、HackⅡとAdctorの混同、保証・未承認数字がない
  • 誤りがあれば媒体へ事実のみで訂正依頼
2. 自社サイト同期
  • Media台帳にカード追加
  • CEOページの出演リストを同期（該当時）
  • 関連Insightsへ文脈リンクを1本だけ
  • python3 scripts/content_guard.py
3. 止める条件
  • 顧客名・成果数字・投資家情報・未許諾映像の公開
  • 迷ったら出さず承認を取る
