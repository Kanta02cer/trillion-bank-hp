ルール

  • 準備度 ≠ 引用率
  • 0% ≠ 失敗
  • 同一条件で再計測
  • Jevは推定：ページ本文から「引用されそうか」を推定した値で、実際のAIの回答ではない。引用率には含めない
  • ChatGPTは検索なし（gpt-4o-mini）で、店名・サービス名が回答に出た割合（言及率）だけを測る。引用は測らない
  • Claudeは検索ありで回答させ、返ってきた引用URLに公式サイトがあるかで判定
  • Perplexityは引用URLの一覧が取れないため、回答本文に公式サイトのドメインがあるときだけ「引用あり」。無いときは判定できない（0%にしない）
  • GitHub Pages上でも計測APIはVercelへ接続します
