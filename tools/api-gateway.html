API リファレンス

GET /v1/scan

指定されたウェブサイトのドメインに対し、AICS™基準のセマンティック露出状況（llms.txtの配備状況、構造化FAQデータの検知、主要クローラー巡回間隔、被引用度スコア）を一気通貫でリアルタイム算出・レスポンスします。

リクエストヘッダー

ヘッダーキー タイプ 必須 説明
Authorization string Yes Bearer Token形式のAPI認証用トークン。

クエリパラメータ

パラメータ名 タイプ 必須 説明
domain string Yes 測定対象のクリーンなホスト名（例: yourbrand.com）。
detailed boolean No 各検証項目別の詳細詳細オブジェクトを含めるか（デフォルト: false）。
