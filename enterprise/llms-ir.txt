---

## IR情報AIコンテキストとは

**IR情報AIコンテキストとは、上場企業の財務情報・業績サマリー・ESGデータをAIが機械可読できるMarkdown/JSON-LD形式で提供するファイルであり、ChatGPT・Perplexity・Google AI Overviewが「投資家の質問」に対して正確な情報を引用・回答できる状態を構築します。**

有価証券報告書のPDF・決算説明会のスライドはAIが直接解析しにくい形式です。このファイルがその「AIへの翻訳機能」を担います。

## IR情報AIコンテキストの設置方法

### 設置パス（推奨）

```
https://[your-domain]/ir/llms.txt           ← IRページ専用コンテキスト
https://[your-domain]/ir/llms-financials.txt ← 財務データ特化
https://[your-domain]/ir/llms-esg.txt       ← ESG情報特化
```

### robots.txtへの追記

```
# IR/ESG AIコンテキストファイル
# ir/llms.txt: https://[your-domain]/ir/llms.txt
# ir/llms-esg.txt: https://[your-domain]/ir/llms-esg.txt
User-agent: GPTBot
Allow: /ir/llms.txt
Allow: /ir/llms-esg.txt
```

## HackⅡ Enterpriseのメリット

1. **決算自動更新**：Edinet・TDnet連携により決算発表後に自動でファイルを更新
2. **インサイダー管理**：未開示情報のフィルタリング機能（コンプライアンス設定）
3. **多言語対応**：日本語・英語版を同時生成（外国人機関投資家向け）
4. **APIアクセス**：BIツール・IRシステムからのデータ取得APIを提供
